# Mistri.xyz — Frontend v0.1

**Har site ka apna soundtrack.**

Current build:
- Full-screen 3-theme visual experience
- Mistri Morning / Cement Mix / Chai Break
- Swipe/drag and keyboard theme navigation
- Glassmorphism bottom player shell
- Theme-specific sound-effect buttons
- GSAP transition foundation
- Howler.js dependency installed for the next audio pass

## Run

```bash
npm install
npm run dev
```

## Audio

The player is intentionally not connected to copyrighted/commercial tracks yet.

Add only audio you have the rights to redistribute under:

```text
public/audio/
public/sounds/
```

Then wire those files into the Howler audio layer.
